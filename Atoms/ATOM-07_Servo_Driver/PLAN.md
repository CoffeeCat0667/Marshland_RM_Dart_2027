# ATOM-07_Servo_Driver 实现方案

## 1. 目标与边界

本模块负责将逻辑舵机目标映射为 PCA9685A 的 IIC/PWM 通道输出，并封装设备初始化、就绪状态查询、目标值写入、最近目标值查询以及 IIC 故障发布。

本模块不负责决定舵机运动流程，不实现安全控制器的整体策略，也不提供 `main` 入口函数。急停和通信异常期间，普通角度目标不得继续下发；安全管理请求的弹簧抬升路径由上层安全逻辑处理，FireController 的目标命令仍应受到安全闸门约束。

## 2. 目录与构建方案

计划采用以下目录结构：

```text
ATOM-07_Servo_Driver/
├── CMakeLists.txt
├── PLAN.md
├── Inc/
│   └── atom_07_servo_driver/   # 对外头文件
└── Src/                        # 非 header-only 实现
```

模块 CMake 使用 `INTERFACE` 目标作为当前初始化状态下的可调用模块目标，避免在尚无实现源文件时引入空源文件或独立编译链；后续加入 `.cpp` 实现时，可将目标平滑调整为静态/对象库而不改变上层调用名称。编译标准和编译器选项由上层工程决定，本目录只声明模块目标、公共头文件路径及模块依赖。

建议目标名：`atom_07_servo_driver`，并提供 `Marshland::atom_07_servo_driver` 别名，供上层通过 `add_subdirectory()` 和 `target_link_libraries()` 接入。

## 3. 接口设计初稿

### 3.1 依赖抽象

- 通过依赖注入使用 IIC 设备访问接口，不在本模块内绑定具体硬件平台驱动。
- 抽象 PCA9685A 的寄存器访问、设备地址、IIC 错误码和故障发布接口。
- Config 负责提供 IIC 设备、PCA9685A 地址、PWM 频率、通道映射、角度范围和脉宽范围。
- 不把库 README 中的参考值当作项目默认配置。

### 3.2 核心能力

1. 根据 Config 打开并初始化 IIC 与 PCA9685A。
2. 初始化后查询并报告驱动就绪状态。
3. 使用 Config 设置 PWM 频率。
4. 校验舵机目标角度是否在配置范围内，并按约定策略处理越界值。
5. 将角度转换为 PWM 脉宽/计数值。
6. 向指定 PCA9685A 通道写入目标值，并返回成功或失败。
7. 查询指定舵机最近一次成功接收的目标值；不得伪装成物理反馈值。
8. 对每次 IIC 错误发布可查询的故障结果。
9. 急停或通信异常状态下拒绝普通角度目标写入。
10. 保证 IIC/PCA9685A 访问串行化。

## 4. 状态与错误处理

- 建议区分：未初始化、初始化中、已就绪、IIC 故障、急停锁定、通信异常等状态。
- 初始化失败、寄存器读写失败、地址/参数非法、通道非法和角度越界应使用明确的错误结果，不用异常吞掉硬件错误。
- 进入急停或通信异常状态后，普通写入接口应保持拒绝，直到由上层安全流程明确恢复。
- 故障信息至少包含错误类别、关联通道（如适用）及底层 IIC 错误信息。
- 最近目标值缓存只在目标成功写入后更新；读取接口不得读取或伪造物理反馈。

## 5. 实现步骤

1. 确认 Public 中已有的 Config、IIC、故障发布和安全状态接口，避免重复定义公共协议。
2. 在 `Inc/` 中定义模块公共类型、配置视图、错误结果和驱动接口。
3. 在 `Src/` 中实现 PCA9685A 初始化、PWM 配置、角度转换、通道写入和目标缓存。
4. 增加 IIC 访问串行化及状态机约束。
5. 接入故障发布，并实现急停/通信异常下的普通命令拒绝。
6. 完善本目录 CMake，使实现源文件和公共头文件随模块目标组织。
7. 在允许的 ARM 构建环境中验证模块可被上层工程调用；不在本目录引入 `main` 或独立平台编译选项。

## 6. 验收清单

- [ ] 单通道目标写入可返回成功/失败。
- [ ] 初始化和就绪状态可查询。
- [ ] PWM 频率、通道、地址、角度范围和脉宽均来自 Config。
- [ ] 角度越界按明确策略处理并可测试。
- [ ] IIC 错误可查询且会发布故障结果。
- [ ] 急停/通信异常期间不会下发普通角度目标。
- [ ] 最近目标值与物理反馈严格区分。
- [ ] PCA9685A 访问串行化。
- [ ] 不存在 `main` 入口函数。
- [ ] 头文件位于 `Inc/`，实现位于 `Src/`。
- [ ] 模块可由上层 CMake 通过 `add_subdirectory()` 调用。
