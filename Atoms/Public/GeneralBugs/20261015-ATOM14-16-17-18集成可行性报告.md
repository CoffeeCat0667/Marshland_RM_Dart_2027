### ATOM-14 Safety Recovery

#### 功能概述
故障管理（23个故障码）、安全闸门、软件急停锁定与人工解除、一般故障自动恢复（固定顺序状态机）、分阶段CAN力矩门控调度。

#### 集成难度：⭐⭐ 中等

**有利因素**：
1. ✅ 代码实现完整（690+行实现，架构合规）
2. ✅ 接入文档齐全（`Rule/ATOM14ConnectProject.md` 240行 + `Guide.md` 393行）
3. ✅ 无循环依赖（单向依赖 Public 契约）
4. ✅ Public 契约已就绪（6个必需端口均由 ATOM-02/15 实现）

**依赖关系**：
- ATOM-02 → `ISafetyStateControl` / `IControlAuthority` / `IInputReporter` / `IStateReader`
- ATOM-15 → `IConfigView` 读取恢复参数
- ATOM-04 → `ISafetyTorqueGate` 控制力矩门控（窄端口适配）
- ATOM-05/10/11/GPIO → 窄端口适配器（恢复动作、电机反馈、限位开关）

**构造函数**：
```cpp
marshland::safety::SafetyRecovery::Ports {

    app::ISafetyStateControl* safety_state;
    app::IControlAuthority* control_authority;

    const IMotorFeedbackReader* motor_feedback;
    IFaultEventSink* fault_events;
}
```

**集成工作量**：
1. **编写5个窄端口适配器**（主要工作量）：
   - `ISafetyTorqueGate` → ATOM-04：力矩门控切换
   - `IRecoveryActions` → ATOM-10/11：恢复动作请求
   - `ILimitSwitchReader` → GPIO：双限位开关读取
   - `IMotorFeedbackReader` → ATOM-05：电机在线判定
   - `IFaultEventSink` → ATOM-18：故障事件推送
2. 在 AppCoordinator 中注入11个端口
3. 绑定 CAN 回调
4. 挂入控制周期（≤100ms）

**验收清单**（Rule/ATOM14ConnectProject.md §8）：
- `portsReady() == true`
- `update()` 已进入控制周期
- WEB/SBUS 人工确认路由到 `onEstopConfirmRequest()`
- ATOM-04 回调已绑定
- 执行器命令路径有 `isOrdinaryCommandAllowed()` 检查

**风险点**：
- ⚠️ 窄端口适配器需理解5个不同机构模块接口
- ⚠️ 换弹抬起的"3s定时+双侧0rpm到位"判据需准确实现

**推荐行动**：✅ **高优先级集成**（路径清晰，文档完备，工作量在适配器开发）

### ATOM-16 HTTP Web

#### 功能概述
HTTP 服务（0.0.0.0:10000），9条 REST API 路由，静态 Web 前端，统一 JSON 请求解析与响应构造，三层验证（状态机/ControlArbiter/SafetyManager）。

#### 集成难度：⭐⭐ 中等

**有利因素**：
1. ✅ 代码实现完整（~1030行，5 hpp + 2 cpp）
2. ✅ 架构清晰（无循环依赖，单向依赖 Public 契约）
3. ✅ 代码质量高（fail-closed、统一错误处理、第三方头隔离）
4. ✅ 第三方库已入库（httplib 0.61.0, nlohmann/json 3.12.0）

**关键阻塞项**：
1. ❌ **未经编译验证**
   - Windows 开发机无法编译（规则禁止 x86 编译链）
   - 首次编译必须在 Ubuntu ARM/aarch64 环境
   - 第三方库在目标平台编译兼容性未验证

2. ⚠️ **8/9 条路由为桩实现**（返回 503）
   - 仅 `GET /api/state` 已实现
   - 需下游接口接通：ATOM-13/14/15/18/19

**依赖关系**：
- ATOM-15 → `IConfigView` 读取 `http.*` 配置
- ATOM-01 → `IMonotonicClock`
- ATOM-02 → `IStateReader` / `IControlAuthority` / `IInputReporter`
- 第三方库 → cpp-httplib 0.61.0 / nlohmann/json 3.12.0

**架构冲突点**：
1. **配置查询能力不足**：`IConfigView` 无法查询 object 和嵌套数组，错误码表硬编码
2. **auto/stop 文档冲突**：Interface.md 与 Config.md 对可用性描述不一致
3. **急停确认通道缺失**：`ISafetyStateControl::ConfirmSoftwareEstop` 注释明确"仅注入安全管理器"
4. **NOT_FOUND 状态码未定义**：Config.md §11.3 映射集合不含 404

**构造函数**：

struct HttpWebModule::Dependencies {
