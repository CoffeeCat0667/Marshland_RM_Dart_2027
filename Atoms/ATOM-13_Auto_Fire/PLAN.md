# ATOM-13 Auto Fire 实现方案

- 更新日期：2026-10-10。
- 设计同步基线：PRD 0.10、PEF 1.5、Interface 1.5、Config 0.8。
- 本轮仅修正文档，不实施 Atomic 功能；模块实现仍需对应负责人及适用授权。

## 1. 目标与边界

`ATOM-13_Auto_Fire`（PEF 四发自动流程执行器）按 PEF v1.5 固定顺序协调四次发射流程。模块只提供流程编排与状态管理，不直接访问 CAN/IIC 寄存器，也不提供 `main` 入口。

模块必须支持被上层 Marshland CMake 工程通过 `add_subdirectory` 引入；编译平台、工具链及全局编译选项由上层工程决定。

## 2. 核心流程

- 自动流程最多执行 4 发，完成第 4 发后进入 `AUTO_COMPLETED`，不得开始第 5 发。
- 第 1 发：蓄力一次（ATOM-08）→按配置运行 →变力一次（ATOM-09）→提交视觉 YAW rpm 目标（ATOM-12）→等待视觉到位或 30 s 回退→进入 `FIRE_READY`→检查停止发射标志及发射授权→调用 ATOM-11。
- 第 2～4 发：蓄力一次（ATOM-08）→请求双 M3508 抬起（ATOM-10）→左右运行目标均成功后按 Config 运行 3 s，两台 0 rpm 目标均成功后抬起到位→供弹→从供弹触发起等待配置的 2 s→请求双 M3508 放下→左右运行目标均成功后按 Config 运行 3 s，两台 0 rpm 目标均成功后放下到位→变力一次（ATOM-09）→视觉 YAW 到位/30 s 回退→`FIRE_READY`→重新检查授权→调用 ATOM-11。
- 每发完成后由主控流程清除 YAW 到位 bool 并记录完成事件；本模块不擅自修改 `stop_fire`。
- `stop_fire == true` 时不得发射，保持 PEF 流程并在 `FIRE_READY` 重新检查。
- SBUS 接管、故障、严重 YAW 超时、急停或其他发射禁止状态按规定终止/转入 ATOM-14；SBUS 接管时当前硬件动作完成后终止，不暂停或恢复旧流程。
- 换弹正常到位及供弹等待期间保持 0 rpm 速度 PID；手动停止、急停或单侧故障立即取消动作/计时，两侧零力矩，不等待正常动作组边界，不接受迟到成功。
- 换弹不设置动作超时，3 s 是配置运行时间。任一目标提交、反馈/PID/CAN 失败不得推进供弹、变力或发射；恢复抬起再次失败交 ATOM-14 锁定 FAULT，不自动循环重试。
- 换弹初始化只建立逻辑默认抬起和两台零转速目标，不主动抬起、回零或软件校准，不接入换弹限位。

## 3. 建议架构

### 3.1 状态机

业务自动流程状态复用 `Atoms/Public/MarshlandTypes.hpp` 的 `AutoFireState`，提交由注入的窄仲裁端口最终委托 ATOM-02，不能另建一份权威业务状态：

- `IDLE`
- `AUTO_PREPARE`
- `CHARGE`
- `FORCE`
- `SHOT_1_YAW`
- `RELOAD_LIFT`
- `FEED`
- `FEED_WAIT`
- `RELOAD_LOWER`
- `SHOT_N_YAW`
- `FIRE_READY`
- `FIRING`
- `FIRE_COMPLETED`
- `AUTO_COMPLETED`
- `AUTO_TERMINATED`

故障系统模式由 ATOM-02 持有；机构内部等待/计时阶段可以有局部进度，但不作为另一份 AutoFireState 或 SystemMode。公共调用端口尚未落地，不能包含 ATOM-02 私有头替代它。

状态推进采用可重复调用的 step/tick 形式，避免阻塞线程；所有超时通过注入的时钟/计时接口计算。

### 3.2 依赖抽象

通过接口或回调注入 ATOM-08、ATOM-09、ATOM-10、ATOM-11、ATOM-12 及控制源/安全状态，PEFExecutor 不直接耦合底层总线实现。建议抽象以下能力：

- 蓄力、变力及持续时间配置读取。
- 双 M3508 抬起/放下请求、两台零转速成功后的定时完成判定、取消和联动失败结果；PEF 不另建 3 s 换弹计时副本。
- 供弹动作执行。
- 发射动作提交及完成判定。
- YAW 目标提交、到位 bool 读取、YAW 超时诊断。
- SBUS/WEB/自动控制源、故障、急停和授权状态读取。
- 发射完成事件、终止原因和诊断事件上报。

### 3.3 数据与契约

- 发次计数范围固定为 `1..4`，启动合法请求时初始化为第 1 发。
- 换弹抬起左正右反，放下左反右正；速度和运行时间由 Config 提供，节点/ID/PID 的待定项不得臆造。0 rpm 闭环保持和零力矩中止必须区分，定时到位不是物理位置反馈。
- 明确区分控制源选择规则与实际发射优先级：实际发射授权优先级为 `SBUS > WEB > 自动流程`。
- 区分“视觉正常到位”和“30 s 回退”；回退只影响尚未完成实际发射的当前发次，已完成发射不得回滚。
- `FIRE_READY` 只读扫描 `stop_fire`，不修改该标志。

## 4. 文件与 CMake 计划

- 头文件放置于 `Inc/`，实现文件放置于 `Src/`。
- 建议头文件：`Inc/PEFExecutor.hpp` 及按需拆分的接口/类型头文件。
- 建议实现文件：`Src/PEFExecutor.cpp`。
- 当前先提供模块级 `CMakeLists.txt` 和本方案；待接口确认后再创建源文件及测试。
- 模块目标暂采用 `INTERFACE` 目标作为初始化阶段的可调用占位；加入实现文件后改为 `STATIC` 或上层指定的库目标，并保持目标名稳定为 `atom_13_auto_fire`。

## 5. 验收与测试计划

1. 合法自动启动后发次从 1 开始，并且每发只执行一次蓄力、变力及对应动作。
2. 第 1 发不执行换弹；第 2～4 发严格执行抬起、供弹等待、放下流程。
3. 第 4 发完成后进入 `AUTO_COMPLETED`，不会产生第 5 发。
4. `stop_fire == true` 时不调用发射动作；标志由外部清除后仍需重新通过授权校验。
5. YAW 正常到位、从供弹触发起算的 2 s 边界、双电机运行 3 s 与两台零转速提交完成边界、30 s 回退可测试。
6. SBUS 接管、急停、故障和发射禁止状态不会继续推进发射；接管时当前硬件动作完成后终止自动流程。
7. 发射完成后延迟到达的视觉状态不会回滚已经完成的发次。
8. 通过上层 ARM 工具链编译；不在本模块引入独立入口或平台专用总线代码。
9. 单侧运行/零转速提交失败、PID/反馈故障、取消与迟到完成事件不推进后续步骤；恢复抬起再次失败锁定 FAULT、不重试。

- PEF/ATOM-14 的终止原因枚举与事件上报接口。
- YAW 到位 bool 的所有权、清除接口及 30 s 回退后的状态读取规则。
