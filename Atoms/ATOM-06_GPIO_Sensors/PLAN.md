# ATOM-06 GPIO 与限位输入：实现方案

## 1. 目标与边界

- 实现 GPIO 与蓄力限位输入适配，不驱动任何机构。
- 按配置周期读取 GPIO，并对输入样本执行去抖。
- 维护每个限位开关的稳定电平与有效状态，提供查询接口。
- 当稳定状态变化时发布 GPIO/限位状态变化事件。
- GPIO 读取失败或输入无效时，向故障管理器报告；不得伪造有效电平。
- 本版本明确不实现压力传感器的接入、采样、状态发布、诊断或安全判定。

## 2. 目录与模块组织

- `Inc/`：公开头文件与接口定义。
- `Src/`：实现文件。
- `CMakeLists.txt`：声明 `atom06_gpio_sensors` 模块目标，供上层工程通过 `add_subdirectory` 使用；不创建可执行文件，不包含 `main`。
- 依赖优先通过抽象接口注入，避免本模块直接绑定具体硬件驱动、事件总线或故障管理器实现。

## 3. 初步接口设计

### 3.1 GPIO 读取抽象

定义 GPIO 读取器接口，至少表达：

- 读取指定 GPIO 的当前样本；
- 成功时返回有效逻辑电平；
- 失败或输入无效时返回明确的失败结果，并携带可供故障管理使用的错误信息/错误码。

### 3.2 去抖与限位状态

为每个限位输入维护独立状态：

- 原始样本/最近样本（如实现去抖所需）；
- 连续样本计数或等价的去抖进度；
- 稳定电平；
- 输入有效性；
- 稳定状态是否发生变化。

去抖参数从配置注入，不在模块内硬编码周期或阈值。只有满足配置定义的去抖条件后，才更新稳定电平并触发状态变化事件。

### 3.3 对外查询与条件判断

提供：

- 查询单个限位的稳定电平；
- 查询单个限位是否有效；
- 判断单个限位是否稳定为低电平；
- 判断蓄力回零条件：两个蓄力限位均有效且稳定为低电平。

蓄力回零不得使用原始样本，也不得在任一输入读取失败/无效时返回成立。

### 3.4 事件与故障报告

通过注入的发布器/回调发布稳定状态变化事件；通过注入的故障报告器报告读取失败和无效输入。事件内容至少能识别输入、稳定电平和有效性变化，避免把读取失败误发布为电平变化。

## 4. 实现步骤

1. 根据现有公共类型和上层 CMake 约定，确定命名空间、错误表示、配置表示及事件接口。
2. 在 `Inc/` 中定义 GPIO 读取器、故障报告器、状态事件发布器和限位状态管理器的最小接口。
3. 在 `Src/` 中实现周期采样、去抖、稳定状态更新、状态查询和蓄力回零判断。
4. 明确处理输入标识非法、配置非法、读取失败和无效输入；所有失败路径保持安全的无效状态。
5. 更新本模块 CMake 的源文件与公共包含目录，并确保目标为可被上层链接的库目标。
6. 增加单元测试或可测试的纯逻辑覆盖，重点验证：
   - 两个稳定限位均为低时才成立回零；
   - 去抖前的瞬时变化不产生事件；
   - 读取失败不产生伪造电平；
   - 无效输入不会使回零条件成立；
   - 本版本不存在压力传感器运行路径。
