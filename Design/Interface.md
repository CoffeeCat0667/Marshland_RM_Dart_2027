## 2. 文档目的与边界

### 2.1 文档目的

本文件定义镖架控制主程序的：

- 总体架构；
- 模块边界；
- 数据流；
- 状态机；
- 控制权仲裁；
- 电机、编码器、GPIO、舵机、CAN、IIC、SBUS、视觉系统、HTTP、WebSocket 和持久化接口；
- 故障、安全和恢复接口；
- 运行时序与接口约束。

本文件用于指导后续实现、联调和测试。具体类名、函数名、线程实现、文件组织和算法实现不在本文件中强制规定。

### 2.2 与其他设计文档的关系

- `Design/PRD.md`：定义产品需求和功能范围。

## 3. 设计约定

### 3.1 规范性用语

- **必须**：实现和接口必须满足的约束。
- **应**：默认必须满足；若不满足，必须记录设计变更。
- **可以**：允许但不是强制要求。
- **配置表定义**：具体值由 `Design/Config.md` 统一配置。
- **库参考值**：来自现有库说明，仅作为配置表初始参考。

### 3.2 控制权优先级

正常实际发射动作的控制优先级严格为：

```text
SBUS > WEB > 自动流程
```

软件急停属于最高安全覆盖行为，不作为普通控制源参与排序：

```text
软件急停 > 所有普通控制源
```

### 3.3 时间基准

所有动作等待、超时和控制周期必须使用单调时钟，不得使用可能被系统校时影响的墙上时钟。

### 4.2 主程序职责

主程序负责：

1. 初始化和管理各输入、通信和硬件模块。
2. 管理控制权和系统运行状态。
3. 按照 `PEF.md` 执行固定四发流程。
4. 协调蓄力、换弹、供弹、变力、发射和 YAW 机构。
5. 直接管理电机闭环、编码器、舵机和 GPIO 接口。
6. 执行一般故障自动恢复和软件急停行为。
7. 向 Web、SBUS、视觉系统和其他外部接口提供状态和结果。

### 4.3 启动顺序

启动顺序如下；具体实现可以调整，但不得违反安全约束：

1. 创建日志和诊断模块。
2. 加载并校验配置和持久化参数。
3. 初始化 SocketCAN。
4. 初始化电机、编码器和 PID 控制。
5. 初始化 GPIO 和限位开关输入（压力传感器本版本不纳入）。
6. 初始化 IIC 和 PCA9685A。
7. 初始化舵机输出和机构初始状态。
8. 初始化 SBUS、视觉系统、HTTP 和 WebSocket 接口。
9. 建立系统状态为“待机”或“初始化失败”。
10. 只有初始化成功后，才允许进入手动或自动发射流程。

## 5. 模块边界

### 5.1 模块总表

| 模块 | 核心职责 | 不负责的内容 |
|---|---|---|
| Bootstrap | 进程启动、关闭、模块生命周期 | 具体机构动作 |
| ControlArbiter | SBUS、WEB、自动流程和软件急停的控制权处理 | 硬件驱动 |
| StateMachine | 系统状态和状态迁移 | 具体 CAN/PWM 报文 |
| PEFExecutor | 执行 `PEF.md` 四发流程 | 直接访问硬件寄存器 |
| ManualController | 处理 SBUS/WEB 手动动作 | 修改控制优先级 |
| SafetyManager | 软件急停、故障分级、自动恢复 | 具体 PID 算法 |
| ChargeController | 蓄力机构两个电机、回零和蓄力动作 | 其他机构流程 |
| ReloadController | 四舵机抬起/放下动作组 | 供弹舵机动作 |
| FeedController | 单舵机供弹动作 | 换弹动作组 |
| ForceController | 变力电机目标和闭环控制 | YAW 流程调度 |
| FireController | 发射机构 `x` 号舵机发射动作 | 自动流程顺序 |
| YawController | YAW 电机 CAN 闭环控制 | 视觉系统业务判断 |
| MotorController | 电机命令、反馈、编码器和 PID | 发射流程状态机 |
| ServoController | 舵机目标角度和 PWM 输出 | 自动流程判定 |
| CANAdapter | SocketCAN 收发和基础报文解析 | 机构业务逻辑 |
| PCA9685AAdapter | Linux IIC 和 PCA9685A 访问 | 机构动作语义 |
| GPIOAdapter | GPIO 输入读取 | 流程决策 |
| SBUSAdapter | SBUS 帧接收、解析和失联检测 | 控制权最终仲裁 |

| WebAdapter | HTTP/WebSocket 交互 | 硬件直接控制 |

| CalibrationController | 校准步骤管理与结果发布 | 机械校准算法实现 |

### 5.2 机构控制层共同约束

所有机构控制器必须提供以下抽象能力：

- `initialize()`：初始化。
- `enable()`：允许控制。
- `disable()`：禁止控制。
- `stop()`：停止当前动作并进入安全状态。
- `getState()`：读取机构状态。
- `getLastError()`：读取最近错误。
- `resetFault()`：在允许条件下清除故障。

机构控制器不得绕过 `ControlArbiter`、`StateMachine` 和 `SafetyManager` 直接接受外部控制请求。

```text
enum ControlSource {

    SBUS,
    WEB,
    AUTO
```

```text
SBUS > WEB > AUTO
```

### 6.2 系统模式

```text
enum SystemMode {

    STANDBY,
    MANUAL,
    AUTO_FIRE,
    DEBUG,
    CALIBRATION,
    RECOVERY,
    SOFTWARE_ESTOP,
    FAULT
}
```

### 6.3 自动流程状态

```text
enum AutoFireState {
    IDLE,
    AUTO_PREPARE,
    CHARGE,
    FORCE,
    SHOT_1_YAW,
    RELOAD_LIFT,
    FEED,
    FEED_WAIT,
    RELOAD_LOWER,
    SHOT_N_YAW,
    FIRE_READY,
    FIRING,
    FIRE_COMPLETED,
    AUTO_COMPLETED,
    AUTO_TERMINATED

```

### 6.4 YAW 到位状态

| 字段 | 类型 | 写入方 | 读取方 | 语义 |
|---|---|---|---|---|
| YAW 目标控制量 | rpm（见 `Design/Config.md` 5.1、10） | 视觉系统；SBUS/WEB 手动控制（按 `SBUS > WEB > 自动流程` 仲裁） | YAW 控制器 | 本次 YAW 目标 |
| 停止发射标志 | `bool` | WEB 前端置 `True`；视觉系统正常 YAW 到位时置 `False`；若视觉系统无响应超时且视觉仍无响应，则控制主系统置 `False` | 自动流程发射授权 | 仅在为 `False` 时允许实际发射 |
| YAW 到位 | `bool` | 视觉系统正常到位置 `True`；视觉系统无响应超时且视觉仍无响应时由控制主系统置 `True`；主程序发射完成后置 `False` | 自动流程/发射授权 | `True` 才允许进入发射授权判断 |

接口必须防止上一发遗留的 `True` 状态被下一发误用。每次新发次开始时必须确认该状态为 `False`；仅在收到本发次有效到位事件，或达到视觉系统无响应回退条件时，才允许置为 `True`。

### 6.5 发射动作数据

```text
FireAction {

    fire_angle: 发射角度;
```

## 7. 状态机

### 7.1 状态转换总表

| 当前状态 | 触发条件 | 下一状态 | 主要动作 |
|---|---|---|---|
| 未初始化 | 启动 | 初始化中 | 初始化模块 |
| 初始化中 | 初始化成功 | 待机 | 建立安全初始状态 |
| 初始化中 | 初始化失败 | 初始化失败 | 禁止发射 |
| 待机 | 进入手动 | 手动 | 接受控制源命令 |
| 待机 | 自动启动 | 自动发射准备（AUTO_PREPARE） | 检查四发前置条件 |
| 自动发射准备（AUTO_PREPARE） | 前置检查通过 | 蓄力（CHARGE） | 执行一次蓄力动作（`X` 秒） |
| 蓄力（CHARGE） | 蓄力完成 | 第 1 发变力（FORCE）/ 换弹抬起 | 第 1 发进入变力；第 2～4 发进入换弹抬起 |
| 第 1 发变力 | 变力到位 | 第 1 发 YAW | 发送视觉目标并控制 YAW |
| 第 1 发 YAW | YAW 到位为 `True`，或视觉系统无响应超时由控制主系统将 YAW 到位置为 `True` 并按到位处理；超时路径同时清除停止发射标志 | 发射前待命 | 等待实际发射授权 |
| 换弹抬起 | 到位判定到期 | 供弹中 | 执行供弹动作 |
| 供弹中 | 供弹动作触发 | 供弹等待 | 开始供弹等待计时 |
| 供弹等待 | 等待到期 | 换弹放下 | 执行放下动作组 |
| 换弹放下 | 到位判定到期 | 换弹后变力 | 执行一次变力动作（`X` 秒） |
| 换弹后变力 | 变力到位 | 下一发 YAW | 控制视觉 YAW |
| 下一发 YAW | YAW 到位为 `True`，或视觉系统无响应超时由控制主系统将 YAW 到位置为 `True` 并按到位处理；超时路径同时清除停止发射标志 | 发射前待命 | 等待实际发射授权 |
| 发射前待命 | 停止标志为 `False` 且授权通过 | 发射中 | 执行一次发射动作 |
| 发射前待命 | 停止标志为 `True` | 发射前待命 | 保持待发，不发射 |
| 发射中 | 发射舵机回待机 | 发射完成 | 清除 YAW 到位信号 |
| 发射完成 | 发次为 1、2 或 3 | 蓄力（CHARGE） | 准备下一发，回到蓄力 |
| 发射完成 | 发次为 4 | 自动完成 | 结束自动流程 |
| 任意自动状态 | SBUS 接管 | 手动 | 当前硬件动作组完成后终止原自动流程 |
| 任意普通状态 | 软件急停 | 软件急停 | 零力矩和禁止发射 |
| 故障 | 自动恢复触发 | 自动恢复 | 执行回零、三次发射、换弹抬起 |
| 自动恢复 | 完成 | 手动 | 不恢复原自动流程 |

### 7.2 状态机约束

1. 未完成初始化不得进入自动发射或手动动作状态。
2. YAW 到位信号不是 `True` 时不得进入实际发射动作；等待超过视觉系统无响应超时后按到位处理并允许进入发射授权检查。
3. 实际发射前必须重新检查控制权、停止发射标志、故障状态和软件急停状态。
4. SBUS 接管自动流程时，原流程在当前硬件动作组完成后终止，不暂停、不恢复。
5. 软件急停状态拒绝一切发射机构舵机操作指令。
6. 状态迁移必须产生可查询的状态事件和原因。
7. 等待 YAW 到位超过视觉系统无响应超时且视觉系统仍无响应时，由控制主系统将 YAW 到位信号置为 `True`、按到位处理并清除停止发射标志；仍须通过发射授权检查。
8. 停止发射标志仅在发射前待命状态被扫描，且仅在为 `False` 时允许实际发射。

## 8. 自动流程接口

### 8.1 第 1 发

```text
AUTO_START
→ AUTO_PREPARE
→ CHARGE：蓄力动作（X 秒）
→ FORCE：变力动作（X 秒）
→ SHOT_1_YAW
→ 视觉系统提供目标 YAW（单位 rpm）
→ CAN 闭环控制 YAW 电机
→ 等待 YAW 到位 bool = True；若视觉系统无响应达到无响应超时，由控制主系统将 YAW 到位置为 True、按到位处理并清除停止发射标志
→ 检查实际发射授权与停止发射标志
→ FIRE_READY
→ FIRING
→ x号舵机：待机角度 → 发射角度 → 保持配置时间 → 待机角度
→ FIRE_COMPLETED
→ 主程序将 YAW 到位设为 False
```

### 8.2 第 2～4 发

```text
CHARGE：蓄力动作（X 秒）
→ RELOAD_LIFT
→ 四舵机抬起动作组
→ 等待抬起到位判定
→ FEED
→ 单舵机：待机角度 → 换弹位角度 → 保持配置时间 → 待机角度
→ FEED_WAIT：从供弹动作触发起等待配置时间
→ RELOAD_LOWER
→ 四舵机放下动作组
→ 等待放下到位判定
→ FORCE：变力动作（X 秒）
→ SHOT_N_YAW
→ 视觉 YAW 到位 bool = True；若视觉系统无响应达到无响应超时，由控制主系统将 YAW 到位置为 True、按到位处理并清除停止发射标志
→ 发射授权与停止发射标志检查
→ FIRE_READY
→ FIRING
→ YAW 到位设回 False
```

### 8.3 停止发射

1. 停止发射标志在准备阶段变为 `True` 时，当前流程继续到发射前待命。
2. 发射前待命状态保持随时可发射，但停止标志为 `True` 时不得实际发射。
3. 正常视觉 YAW 到位时由视觉系统将停止发射标志置为 `False`；若视觉系统无响应超时且视觉系统仍无响应，则由控制主系统将 YAW 到位信号置为 `True` 并将其停止发射标志置为 `False`。自动流程在发射前待命状态扫描该标志，仅在为 `False` 时发射。
4. 停止标志解除后，实际发射仍按 `SBUS > WEB > AUTO` 授权。
5. 停止标志为 `True` 时不得开始下一发。

## 9. 控制权与外部输入接口

### 9.1 SBUS 接口

| 项目 | 定义 |
|---|---|
| 输入设备 | 天地飞 ET16S 接收机 |
| 输入协议 | SBUS |
| 控制优先级 | 高于 WEB 和自动流程 |
| 手动控制 | 支持 |
| 软件急停 | 支持 |
| 通道映射 | 由 `Design/Config.md` 配置表定义 |
| 失联判定 | 由 `Design/Config.md` 配置表定义 |
| 串口设备 | 由 `Design/Config.md` 配置表定义 |
| 波特率/串口格式 | 由 `Design/Config.md` 配置表定义 |
| 自动模式标志 | 由配置表的「自动模式」通道定义；置位时控制源为 `AUTO`，此时 SBUS 与 WEB 仍可介入自动流程 |
| 反相/电平转换 | 已经过硬件反向电路（硬件事实） |

SBUS 通道映射、有效范围、中立值和失联行为由配置表定义。SBUS 解析器必须输出统一的控制源、控制命令、信号有效状态和失联状态，不直接执行机构动作。

### 9.2 WEB 控制接口

WEB 控制优先级低于 SBUS，高于自动流程。WEB 控制请求不得绕过：

- 系统状态机；
- 软件急停；
- 发射前置条件；
- 限位和故障保护；
- 实际发射优先级。

WEB 手动控制动作集（`charge_start`、`charge_stop`、`charge_home`、`reload_lift`、`reload_lower`、`feed_once`、`force_set`、`yaw_set`、`servo_set`、`fire_once`、`stop_fire_set`、`stop_fire_clear`、`auto_start`、`auto_stop`）及其约束由 `Design/Config.md` 11.4 定义。

WEB stop_fire_clear 为第三条停止发射标志清除路径，仅允许在手动/调试模式执行。执行该动作前必须退出自动模式并转入手动模式；该动作清除停止发射标志，但同时终止当前自动流程，禁止自动流程继续或恢复。WEB 控制请求必须携带请求标识和控制源标识。WEB 断线、控制权变化和控制请求结果必须通过统一状态接口反馈。

### 9.3 视觉系统接口

| 方向 | 数据 | 类型 | 语义 |
|---|---|---|---|
| 视觉系统 → 主程序 | 指定 YAW 目标控制量 | rpm（见 `Design/Config.md` 10） | 本次发射目标；视觉系统内部按 px 误差判到位 |
| 视觉系统 → 主程序 | YAW 到位 | `bool` | `True` 才允许进入发射授权判断 |
| 主程序 → 视觉系统 | 清除 YAW 到位 | `False` | 发射动作完成后执行 |
| 控制主系统（超时回退） | YAW 到位置为 `True` | `bool` | 视觉系统无响应超时且视觉仍无响应时执行，用于激活发射 |
| SBUS/WEB → 主程序 | 手动 YAW 目标控制量 | rpm | 手动 YAW 控制，遵循 `SBUS > WEB > 自动流程` |

视觉系统的实际通信承载、消息字段和部署参数由 `Design/Config.md` 配置表定义。视觉系统无响应达到无响应超时属正常回退路径：由控制主系统将 YAW 到位 bool 置为 `True` 并清除停止发射标志，再进入发射授权检查。接口语义必须满足：

1. 新发次开始前不得使用上一发遗留的 `True` 状态。
2. YAW 到位为 `True` 且控制权授权通过后，才允许执行发射动作。
3. 发射动作完成后，主控制程序将 YAW 到位状态设回 `False`。
4. 无效或失联状态不得触发发射；YAW 电机超过 2000 ms 未完成调整时仍继续等待视觉系统，只有达到 30000 ms 且视觉仍无响应时，才允许按正常回退规则处理。
5. 手动 YAW 目标遵循 `SBUS > WEB > 自动流程` 仲裁，不得绕过发射授权。

## 9.4 视觉迟到状态

1. 30 s 回退后恢复的迟到视觉状态，只能作用于尚未执行实际发射的当前发次。
2. 当前发次尚未发射时，按最新视觉状态重新执行 YAW 到位检查；重新检查通过前不得发射。
3. 当前发次已经发射完成时，迟到视觉状态不得回滚已完成动作，仅写入诊断事件。

## 14. HTTP 接口

### 14.1 服务边界

HTTP 负责非持续控制请求、状态查询、参数管理和前端资源访问。HTTP 请求不得绕过控制权仲裁和安全状态。

以下部署参数由 `Design/Config.md` 配置表定义：

- 监听地址；
- 端口；
- 静态资源提供方；
- 请求体和响应体大小限制。

当前产品规则：

- 用户登录：不需要；
- 权限等级：不需要；
- 普通操作二次确认：不需要；
- 软件急停恢复：必须人工确认。

### 14.2 HTTP 路由

| 方法 | 路径 | 用途 | 控制源 | 状态限制 |
|---|---|---|---|---|
| GET | `/api/state` | 查询系统总状态 | 无 | 始终可读 |
| GET | `/api/diagnostics` | 查询诊断和故障 | 无 | 始终可读 |
| POST | `/api/control/auto/start` | 启动自动流程 | WEB | 仅允许状态 |
| POST | `/api/control/auto/stop` | 设置停止发射 | WEB | 始终可用 |
| POST | `/api/control/manual` | 手动控制 | WEB | 受仲裁限制 |
| POST | `/api/control/estop` | 触发软件急停 | WEB | 始终可用 |
| POST | `/api/control/estop/confirm` | 人工确认解除急停 | WEB | 急停状态 |
| GET/POST | `/api/parameters` | 查询或修改参数 | WEB | 由配置表和状态限制 |
| POST | `/api/calibration` | 校准操作 | WEB | 无需模式前提；无急停、活动故障时可用 |

请求、响应、错误码和字段结构由 `Design/Config.md` 配置表定义。

链路与模式进入：`/api/control/manual` 动作集链路用于正常状态下的手动/自动操作；`/api/control/auto/start` 与 `/api/control/auto/stop` 是应急链路。校准模式与调试模式的进入无需前提（急停或活动故障锁定时除外），校准通过 `/api/calibration` 进入，调试模式通过调试类动作进入；不新增独立模式路由。

## 18. 故障与安全接口

### 18.1 已确定安全规则

| 场景 | 必须行为 |
|---|---|
| 实际发射授权 | 严格遵守 `SBUS > WEB > 自动流程` |
| SBUS 接管自动流程 | 原自动流程在当前硬件动作组完成后终止，不暂停、不恢复 |
| 一般故障恢复 | 蓄力机构两个电机回零 → 仅发射机构三次发射，其他电机零力矩、其他舵机角度不变 → 换弹抬起 → 进入手动状态 |
| 软件急停 | 所有电机持续零力矩 CAN 帧、换弹抬起、拒绝发射机构舵机指令 |
| 急停人工解除 | 换弹抬起、蓄力机构两个电机回零、不重新初始化、不自动恢复原自动流程 |
| YAW 未到位 | 未达到视觉系统无响应超时前禁止发射；超时后由控制主系统将 YAW 到位置为 `True` 并按到位处理 |
| 发射完成 | 主程序将 YAW 到位 bool 设回 False |

### 18.2 故障接口

故障码、触发条件、故障等级、自动恢复条件和人工确认条件由 `Design/Config.md` 配置表定义。故障管理模块必须提供：

- 当前故障；
- 历史故障；
- 故障发生时间；
- 故障来源；
- 故障严重级别；
- 自动恢复状态；
- 人工确认状态；
- 故障清除结果；
- 向 WebSocket 推送故障事件。

软件急停是不可自动恢复的安全状态；人工确认后执行换弹抬起和蓄力机构两个电机回零，不重新初始化且不自动恢复原自动流程。

`Config.md` 是上述具体配置的唯一来源。实现不得在代码中创建与配置表冲突的隐含默认值。

## 21. 正式接口约束

1. 所有外部接口必须遵守本文件定义的数据方向、控制权、安全状态和生命周期。
2. 具体配置值必须从 `Design/Config.md` 加载或由配置系统提供。
3. 配置缺失、读取失败或格式错误时，按持久化和故障安全规则处理。
4. `PRD.md`、`PEF.md`、`Interface.md` 和 `Config.md` 不得出现互相矛盾的流程语义。
5. PEF 中已定义的四发流程是本接口流程编排的上位约束。
6. 软件急停、一般故障恢复和 SBUS 抢占不得被普通 WEB 或自动流程接口绕过。
7. 本文件不定义具体算法实现，但实现必须能够通过本文件接口验证和测试。
