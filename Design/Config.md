### 6.2 CAN 报文接口表

| 报文类别 | 方向 | CAN ID | DLC | 字段/编码 | 完整帧 | 单位/缩放 | 周期/触发 | 超时/错误处理 |

| 错误状态 | 设备 → 主程序 | 与电机反馈同帧 | 8 | 设备错误码，映射见 5.2 | 大端序解析 | 原始帧 | 设备上报时 | 按 14.2 故障表处理 |
| 零力矩帧 1 | 主程序 → 电机 | `0x200` | 8 | 全部置零 `0000000000000000` | `1.200#0000000000000000` | 原始帧 | 每 20 ms | 发送失败进入错误状态，全机静默 |
| 零力矩帧 2 | 主程序 → 电机 | `0x1FF` | 8 | 全部置零 `0000000000000000` | `2.1FF#0000000000000000` | 原始帧 | 每 20 ms | 发送失败进入错误状态，全机静默 |

字节序规则：所有多字节量一律使用**大端序**，每个 int16_t 先写高字节、再写低字节。示例（配置 0x201 电机电流值）：

```c
uint8_t buffer[8];
int16_t Example = 1000;
buffer[0] = (Example >> 8) & 0xFF;  // 高字节
buffer[1] = Example & 0xFF;         // 低字节
```

### 7.1 SBUS 功能映射表

信号量约定：

- **摇杆量**：以 1024 为中心的连续量，有效范围为 1024 ± 660，即 364～1684；超出该范围视为无效。
- **开关量**：仅取 364、1024、1684 三个离散值。

| 功能 | 通道 | 信号类型 | 有效范围 | 中立/默认值 | 失联行为 |
|---|---|---|---|---|---|
| 进入/退出手动模式 | CH6 | 开关 | 364/1024/1684 | 1024 | 降级至 WEB；重连后自动恢复 SBUS 最高控制权 |
| **自动模式** | CH6 | 开关 | 364/1024/1684（1684 为 True） | 1024 | 同上；失联后控制源按 7.2 选择 |
| 软件急停触发 | CH5 | 开关 | 364/1024/1684 | 1024 | 同上 |
| 软件急停人工确认 | [待定] | 开关 | 364/1024/1684 | 1024 | 同上 |

| `timestamp` | UTC ISO 8601 毫秒时间戳；周期和超时计算使用单调时钟 |
| `request_id` | 请求关联标识 |
| `source` | `WEB`；服务端推送统一标识为 `WEB`，不随事件原始来源变化 |

### 12.3 服务端消息类型

| 消息类型 | 内容 | 字段定义 |
|---|---|---|
| `system_state` | 系统模式、自动流程状态、控制源 | `system_mode`、`initialized`、`control_source`、`auto_fire_state`、`current_shot`、`total_shots`、`stop_fire`、`estop_active` |

| `fault` | 当前故障、故障码、恢复状态 | `active_faults` 数组；每项含 `code`、`severity`、`message`、`occurred_at`、`recovery_state` |

| `parameter_changed` | 参数修改结果 | `key`、`accepted`、`persisted`、`effective`、`error_code` |
| `error` | 协议或请求处理错误 | `code`、`message`、`details`、`request_id` |

## 14. 故障、安全与恢复配置

### 14.1 已确定安全规则

| 场景 | 固定行为 |
|---|---|
| 实际发射授权 | 严格遵守 `SBUS > WEB > 自动流程` |
| SBUS 接管自动流程 | 当前硬件动作组完成后终止，不暂停、不恢复 |
| 一般故障恢复 | 蓄力机构两个电机回零 → 仅发射机构执行三次发射动作 → 换弹抬起 → 进入手动状态 |
| 一般故障恢复期间其他电机 | 零力矩 |
| 一般故障恢复期间其他舵机 | 角度保持不变 |
| 软件急停 | 所有电机持续发送零力矩 CAN 帧；换弹抬起；拒绝发射机构舵机指令 |
| 软件急停人工解除 | 换弹抬起、蓄力机构两个电机回零；不重新初始化；不自动恢复原自动流程 |
| YAW 未到位 | 未达到 30 s 无响应超时前禁止发射；超时后由控制主系统将 YAW 到位信号置为 `True` 并按到位处理 |
| 发射完成 | 主控制程序将 YAW 到位信号设回 `False` |
| 通信异常时电机 | 零力矩 |
| 通信异常时舵机 | 保持当前角度 |
| 通信异常时发射舵机 | 禁止改变角度 |

## 15. 线程、并发与调度配置

| 项目 | 当前定义 |
|---|---|
| 电机闭环任务 | 独立线程 |
| SocketCAN 接收任务 | 独立任务 |
| SocketCAN 发送任务 | 独立任务 |
| IIC/PCA9685A 访问 | 串行访问 |
| 状态机与机构控制器同步 | 数据零拷贝 |
| 控制权变化 | 当前硬件动作组完成后停止后续低优先级动作，并执行更高优先级控制源命令 |
| 2 秒供弹等待期间 | 持续执行电机闭环和安全监测 |
| 软件急停变量 | 统一 `bool` 变量；`True` 表示锁定急停，人工确认并完成解除动作后设为 `False` |
| 执行器普通动作前急停检查 | 必须检查；急停为 `True` 时拒绝普通命令 |
| 安全动作例外 | 零力矩、换弹抬起、人工确认后的蓄力机构两个电机回零不受普通命令拒绝规则影响 |
| 电机闭环任务优先级 | 高；固定周期执行，低于安全急停任务，高于业务和网络任务 |
| 状态机任务优先级 | 高；高于 IIC 和网络任务，接收安全事件后优先调度 |
| IIC 任务优先级 | 中高；安全动作队列高于普通舵机队列 |
| 网络任务优先级 | 低；不得阻塞控制和安全任务 |
| 线程调度策略 | Linux `SCHED_OTHER`；固定周期任务使用单调时钟绝对期限并监测超期，不依赖特权实时调度；属于尽力调度，不构成硬实时保证 |
| 线程栈大小 | 1 MiB；每个应用工作线程建议值，遵守平台最小值限制 |

## 17. 配置表维护规则

1. 本表是所有硬件通道、报文、数值参数、运行参数和配置型策略的唯一来源。
2. `Interface.md` 不重复写入本表的具体配置值，只定义接口契约、固定流程和语义。
3. `PRD.md`、`PEF.md`、`Interface.md` 和本表不得出现互相矛盾的具体配置或流程语义。
4. `[待定]` 表示预留接入点；具体值在对应硬件或协议接入时补充，实现不得臆造。
5. `[由AGENT确定]` 表示由 Agent 依据现有设计与资料确定；本表 v0.7 已将其全部替换为具体值。
6. 配置修改必须同步更新版本号和日期。
7. 配置加载失败、格式错误或缺失时，按本表故障策略和安全规则处理。
8. 实现不得创建与本表冲突的隐含默认值。
9. 配置项发生变化时，必须同步检查 PRD、PEF、Interface 和测试用例的一致性。
