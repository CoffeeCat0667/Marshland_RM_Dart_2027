## 2. 术语

| 术语 | 定义 |
|---|---|
| 视觉 YAW 控制 | 视觉系统提供指定 YAW 控制量（单位 rpm），主程序通过 CAN 闭环控制 YAW 电机执行。 |
| 视觉系统无响应超时 | 等待视觉系统将 YAW 到位信号置为 `True` 超过 30 s；超时后由控制主系统将该信号置为 `True`、清除停止发射标志并按到位处理，在发射授权满足时允许发射。 |
| YAW 调整超过 2000 ms | 不立即终止当前发次；继续等待视觉系统，直至 30 s 视觉无响应超时。 |
| 视觉在 30 s 内恢复 | 立即清除 F-VISION-001、恢复视觉通信、重新要求当前发次 YAW 到位信号并重新开始 30 s 计时；不触发一般故障恢复。 |
| 30 s 回退后的视觉恢复 | 将 F-VISION-001 转为已处理且不保留失联状态；下一发允许使用视觉，迟到的视觉状态仍可影响当前已完成回退的发次。 |
| 蓄力动作 | 蓄力机构以恒定速度运行配置时间 `X` 秒，到期判定蓄力完成。 |
| 变力动作 | 变力机构执行配置时间 `X` 秒，到期判定变力到位。 |
| YAW 到位信号 | 视觉系统提供的 `bool` 变量；值为 `True` 表示当前 YAW 已达到本次指定控制量（rpm）对应的到位判据，值为 `False` 表示未到位或已清除；30 s 无响应回退时由控制主系统置为 `True`。 |
| 换弹抬起/放下 | 换弹机构四个舵机分别执行对应动作组后，在动作组角度命令发送 500 ms 后判定到位。 |
| 供弹 | 供弹机构单舵机从待机角度切换至换弹位角度，保持 100 ms 后回到待机角度的动作。 |
| 发射动作 | 发射机构 `x` 号舵机由“待机”角度切换到“发射”角度，保持 100 ms 后切换回“待机”角度；回到待机角度后判定完成一次发射。 |
| 停止发射标志 | 值为 `True` 时，禁止执行当前发射动作和开始下一发；由 WEB 前端置 `True`；视觉正常回传 YAW 到位时由视觉系统置 `False`；等待视觉到位超过 30 s 且视觉系统仍无响应时，由控制主系统将 YAW 到位信号置为 `True` 并将该标志置 `False`；当前准备流程可继续至发射前待命状态。 |
| 软件急停 | 由 Web 前端或 ET16S 遥控器触发的锁定安全状态。 |

## 3. 控制优先级与仲裁

实际发射动作触发权严格按照以下优先级处理：

```text
SBUS > WEB > 自动流程
```

具体规则如下：

1. SBUS 控制优先于 WEB 控制，WEB 控制优先于自动流程控制。
2. 低优先级控制不得覆盖、绕过或抢占高优先级控制。
3. 当 SBUS 取得控制权时，正在执行的原自动发射流程在当前硬件动作组完成后终止，不暂停、不恢复。
4. 自动流程只有在没有更高优先级控制有效接管，且所有发射前置条件满足时，才可以触发实际发射。
5. 软件急停属于最高安全行为，无论由何种入口触发，均立即覆盖普通 SBUS、WEB 和自动流程控制。
6. 控制源选择规则：程序启动且无 WEB 客户端连接时控制源为 `AUTO`；存在 WEB 连接时为 `WEB`；SBUS「自动模式」标志位为 `True` 时控制源为 `AUTO`，此时 SBUS 与 WEB 仍可正常介入自动流程；该标志位为 `False` 时按 `SBUS > WEB` 选择；SBUS 失联时降级至 WEB，重连后自动恢复 SBUS 最高控制权。控制源选择不改变实际发射授权的 `SBUS > WEB > 自动流程` 顺序。

## 4. 自动发射总则

1. 自动流程固定总弹数为 4 发。
2. 每一发均执行蓄力、变力和 YAW 控制步骤。第 1 发顺序为：蓄力 → 变力 → 视觉 YAW 控制 → 发射；第 2 至第 4 发顺序为：蓄力 → 换弹抬起 → 供弹 → 等待 → 换弹放下 → 变力 → 视觉 YAW 控制 → 发射。
3. YAW 电机调整超过 2000 ms 时不立即终止等待；继续等待视觉系统。仅当视觉在 30 s 内仍无有效响应时，才由控制主系统将 YAW 到位信号置为 `True`、清除停止发射标志并按到位处理。
4. 第 1 发不执行换弹和供弹；第 2 至第 4 发均执行换弹、供弹、等待、变力、YAW 控制和发射流程。
5. 连续发射无额外固定发射间隔。
6. 每次发射动作完成后，主控制程序必须将视觉系统 YAW 到位信号设回 `False`，为下一次 YAW 到位判定做准备。
7. 视觉系统正常将 YAW 到位信号置为 `True` 时，由视觉系统将停止发射标志置为 `False`；若等待视觉到位超过 30 s 且视觉系统仍无响应，则由控制主系统将 YAW 到位信号置为 `True`、将停止发射标志置为 `False`，按超时到位处理。自动流程仅在发射前待命状态扫描该标志，且仅在标志为 `False` 时执行实际发射。
8. 手动 YAW 控制（SBUS 或 WEB）遵循 `SBUS > WEB > 自动流程` 仲裁，与自动流程的视觉 YAW 目标互斥，不得绕过发射授权。
9. 停止发射、故障、通信异常、急停或高优先级控制接管时，不得继续触发不符合控制权的发射动作。

## 5. 四发自动发射流程

### 5.1 第 1 发

1. 程序进入允许自动发射的状态。
2. 蓄力机构执行一次蓄力动作：以恒定速度运行配置时间 `X` 秒，到期判定蓄力完成。
3. 变力机构执行一次变力动作：执行配置时间 `X` 秒，到期判定变力到位。
4. 视觉系统提供本次指定 YAW 控制量（单位 rpm）。
5. 主程序通过 CAN 闭环控制 YAW 电机转至指定值。
6. 主程序等待视觉系统将 YAW 到位信号置为 `True`；若超过视觉系统无响应超时 30 s 且视觉系统仍无响应，则由控制主系统将该信号置为 `True`、将停止发射标志置为 `False`，按到位处理。
7. 进入发射前待命状态，扫描停止发射标志并进行发射前置条件检查，包括控制权、停止发射标志、故障状态和软件急停状态。
8. 停止发射标志为 `False` 且前置条件满足后，执行一次发射动作：`x` 号舵机由“待机”角度切换到“发射”角度，保持 100 ms 后切换回“待机”角度。
9. `x` 号舵机回到“待机”角度后，判定第 1 发完成。
10. 发射完成后，主控制程序将 YAW 到位信号设回 `False`。
11. 若流程未被停止、故障或高优先级控制接管，则进入第 2 发准备。

### 5.2 第 2 发

1. 检查停止发射标志和控制权；不满足条件时，不启动本发流程。
2. 蓄力机构执行一次蓄力动作：以恒定速度运行配置时间 `X` 秒，到期判定蓄力完成。
3. 换弹机构执行抬起动作组。
4. 动作组角度命令发送后等待 500 ms，判定换弹机构抬起到位。
5. 供弹机构执行一次供弹动作：由待机角度切换到换弹位角度，保持 100 ms 后回到待机角度。
6. 从供弹动作触发时刻开始等待 2 秒。
7. 换弹机构执行放下动作组。
8. 动作组角度命令发送后等待 500 ms，判定换弹机构放下到位。
9. 变力机构执行一次变力动作：执行配置时间 `X` 秒，到期判定变力到位。
10. 视觉系统提供本次指定 YAW 控制量（单位 rpm），主程序通过 CAN 闭环控制 YAW 电机。
11. 主程序等待视觉系统将 YAW 到位信号置为 `True`；若超过 30 s 且视觉系统仍无响应，则控制主系统将该信号置为 `True` 并将停止发射标志置为 `False`，按到位处理。
12. 进入发射前待命状态，扫描停止发射标志并重新检查控制权、停止发射标志、故障状态和软件急停状态。
13. 停止发射标志为 `False` 且前置条件满足后，立即执行一次发射动作。
14. 发射动作完成后，将 YAW 到位信号设回 `False`。
15. 若流程未被停止、故障或高优先级控制接管，则进入第 3 发准备。

### 5.3 第 3 发

第 3 发与第 2 发流程完全相同：

> 蓄力 → 换弹抬起 → 动作组角度命令发送后等待 500 ms → 触发供弹 → 供弹触发起等待 2 秒 → 换弹放下 → 动作组角度命令发送后等待 500 ms → 变力 → 视觉 YAW 控制 → 等待 YAW 到位信号为 `True`（或 30 s 无响应超时后由控制主系统置为 `True` 并按到位处理）→ 执行发射动作 → 发射完成后将 YAW 到位信号设回 `False`。

完成第 3 发后，若流程未被停止、故障或高优先级控制接管，则进入第 4 发准备。

### 5.4 第 4 发

第 4 发与第 2 发流程完全相同：

> 蓄力 → 换弹抬起 → 动作组角度命令发送后等待 500 ms → 触发供弹 → 供弹触发起等待 2 秒 → 换弹放下 → 动作组角度命令发送后等待 500 ms → 变力 → 视觉 YAW 控制 → 等待 YAW 到位信号为 `True`（或 30 s 无响应超时后由控制主系统置为 `True` 并按到位处理）→ 执行发射动作 → 发射完成后将 YAW 到位信号设回 `False`。

第 4 发完成后，自动流程结束，不得开始第 5 发。

## 6. 停止发射行为

1. 停止发射标志为 `True` 时，不得执行当前发射动作，也不得开始下一发。
2. 若停止发射标志在当前发射流程的准备阶段变为 `True`，当前准备流程继续执行至“发射”动作前的发射前待命状态。
3. 进入发射前待命状态后，系统保持随时可发射，但在停止发射标志为 `True` 期间不执行实际发射；自动流程在发射前待命状态扫描该标志，仅在标志为 `False` 时发射。
4. 视觉系统正常回传 YAW 到位时由视觉系统清除停止发射标志；等待视觉到位超过 30 s 且视觉系统仍无响应时，由控制主系统将 YAW 到位信号置为 `True` 并清除停止发射标志。该标志不因 FIRE_READY 扫描本身自动改变。
5. 停止发射标志解除后，实际发射触发权仍严格遵守 `SBUS > WEB > 自动流程`；没有对应控制权时，自动流程不得自行越权发射。
6. 软件急停不适用上述收尾等待规则，应立即进入软件急停流程。

## 7. 一般故障自动恢复流程

一般故障允许自动恢复。恢复动作按以下顺序执行：

1. 蓄力机构两个电机执行回零。
2. 仅当两个限位开关均处于低电平时，判定蓄力机构两个电机回零完成。
3. 蓄力机构两个电机回零完成后，仅发射机构执行三次发射动作。
4. 每次发射动作定义为：`x` 号舵机由“待机”角度切换到“发射”角度，保持 100 ms 后切换回“待机”角度；舵机回到“待机”角度后，判定本次发射动作完成。
5. 三次发射动作期间，其他机构的电机保持零力矩，其他舵机角度保持不变。
6. 三次发射动作完成后，换弹机构执行抬起动作组。
7. 动作组角度命令发送后等待 500 ms，判定换弹机构抬起完成。
8. 自动恢复期间，不得启动或继续自动发射。
9. 自动恢复完成后，系统进入手动状态；原自动发射流程不自动恢复或继续。

## 8. 软件急停流程

### 8.1 触发入口

软件急停可由以下任一入口触发：

- Web 前端；
- ET16S 遥控器的 SBUS 控制链路。

### 8.2 急停锁定动作

软件急停触发后，系统必须立即执行并持续保持以下行为：

1. 对所有电机持续发送零力矩 CAN 帧。
2. 换弹机构执行抬起动作组。
3. 拒绝一切操作发射机构舵机的指令。
4. 禁止自动发射、连续发射和任何新的发射流程步骤。
5. 保持软件急停锁定状态，直至人工确认解除。

### 8.3 人工确认解除

1. 软件急停不能自动解除。
2. 必须由 Web 前端或 ET16S 遥控器执行人工确认。
3. 人工确认解除后，不需要重新初始化。
4. 人工确认解除后，换弹机构执行抬起动作，蓄力机构两个电机执行回零动作；蓄力机构仅在两个限位开关均为低电平时判定回零完成。
5. 人工确认解除后的恢复动作完成前，不得执行自动发射。
6. 软件急停解除本身不得自动恢复原自动发射流程；实际控制仍严格遵守 `SBUS > WEB > 自动流程`。

## 9. 异常处理原则

1. YAW 到位信号为 `False` 时不得触发发射；等待超过 30 s 且视觉系统仍无响应时，由控制主系统将 YAW 到位信号置为 `True` 并清除停止发射标志，按到位处理，之后仍须通过发射授权检查。
2. 每次发射完成后，主控制程序必须将 YAW 到位信号设回 `False`。
3. 发生故障、通信异常、输入异常或动作超时时，必须阻止不符合当前控制权的后续发射步骤。
4. 一般故障进入自动恢复流程；软件急停进入锁定急停流程。
5. SBUS 接管自动流程时，原自动流程在当前硬件动作组完成后终止，不暂停、不恢复。
6. 控制优先级和安全处理以本文件第 3、6、7、8 节为准。

## 10. 正式基线说明

1. 本文件中的“发射动作”仅指发射机构 `x` 号舵机完成一次“待机 → 发射，保持 100 ms → 待机”的动作。
2. 本文件中的四发自动流程总数固定为 4，不存在第 5 发。
3. 第 1 至第 4 发均执行蓄力与变力；第 2 至第 4 发另执行换弹与供弹。
4. 视觉系统无响应超时为 30 s；超时且视觉系统仍无响应时，控制主系统将 YAW 到位信号置为 `True`、按到位处理并清除停止发射标志。
5. 本文件不定义具体舵机通道、角度值、CAN ID、PID 参数、GPIO 编号、SBUS 通道编号或其他设备参数。
6. 上述参数和通信字段由 `Design/Config.md` 配置表定义。
7. 本文件为程序运行流程正式基线；后续流程变更必须同步修订本文件及关联设计文档。

## 10.1 视觉迟到状态处理

1. 30 s 回退后恢复的迟到视觉状态，只能影响尚未执行实际发射的当前发次。
2. 当前发次尚未发射时，按最新视觉状态重新执行 YAW 到位检查；重新满足到位和发射授权条件前，不得发射。
3. 当前发次已经完成发射时，迟到视觉状态不得回滚已完成动作，仅记录诊断事件。
