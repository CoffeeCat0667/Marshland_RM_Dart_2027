## 单一职责

控制蓄力机构两个电机（Config 电机 ID 1、2）的正常恒速蓄力、停止和限位回零，并维护蓄力机构状态。

## 内部原子操作

1. 校验一个蓄力命令的运行模式、控制权和安全条件。
2. 分别向蓄力电机 1、2 提交配置的恒定速度目标。
3. 从本次蓄力开始时刻启动 Config 蓄力时间 X 计时。
4. X 秒到期后结束正常蓄力并将动作状态设为完成。
5. 接受一个普通停止蓄力请求并停止两个电机的普通蓄力目标。
6. 向蓄力电机 1 提交回零目标。
7. 向蓄力电机 2 提交回零目标。
8. 读取两个限位开关的稳定状态。
9. 仅当两个限位均为低电平时停止两个电机的回零目标并标记回零完成。
10. 查询蓄力状态、目标、完成状态或最近错误。
11. 将蓄力超时、电机或限位错误报告给 ATOM-14。

## 与自动流程的关系

- 固定四发流程中第 1～4 发均各执行一次正常蓄力。
- 故障恢复与急停人工解除调用的是两个蓄力电机回零，不是正常蓄力 X 秒动作。
- 蓄力 X、速度、最大动作时间等从 Config 获取。

## 安全约束与验收

- 初始化失败、急停锁定或控制授权不通过时拒绝普通蓄力启动。
- X 秒到期前不报告正常蓄力完成。
- 两限位未同时低时不报告回零完成。
- 回零请求明确覆盖电机 ID 1 与 2。
