# ATOM-01：进程生命周期与启动协调

## 元信息

| 项目 | 内容 |
|---|---|
| Atom ID | ATOM-01 |
| 功能类 | 进程生命周期与启动协调 |
| 程序代号 | Marshland |
| 状态 | 启用 |
| 来源 | PRD 7.1；Interface 4.2、4.3、5.1、7.1；Config 3、13 |
| 同步基线 | PRD 0.9、PEF 1.4、Interface 1.4、Config 0.7；2026-09-26 |
| 上游/下游 | 上游：操作系统启动；下游：状态机、驱动适配器、机构控制器 |

## 单一职责

管理应用进程和各模块的生命周期，按安全启动顺序创建模块、收集初始化结果，并决定系统进入待机或初始化失败状态。此 Atom 不执行发射流程或机构动作。

## 输入与输出

- 输入：进程启动/关闭事件、Config 参数、各模块初始化结果。
- 输出：模块生命周期命令、系统启动结果、待机/初始化失败状态。
- 所有具体设备和动作参数从 Config 读取；不得在本 Atom 中补造 `[待定]` 数值。

## 内部原子操作

1. 创建日志/诊断资源。
2. 加载并解析 JSON 配置文档。
3. 校验必需配置项；可选项按 Config 默认规则处理。
4. 加载电机 PID 参数。
5. 初始化 SocketCAN 适配器。
6. 逐个初始化电机和编码器通道。
7. 初始化 GPIO 与限位输入。
8. 初始化 IIC/PCA9685A。
9. 初始化舵机输出状态。
10. 初始化 SBUS 与视觉接口。
11. 启动 HTTP 和 WebSocket 服务。
12. 汇总必需模块 readiness。
13. 全部必需模块成功时将系统切换为 STANDBY。
14. 必需模块失败时将系统切换为 INIT_FAILED 并禁止正常执行器动作。
15. 收到关闭事件时逐个停止模块并释放资源。

每一项单独执行并返回结果；启动协调器只根据结果推进下一项，不隐藏多模块副作用在单一不可分割操作内。

## 安全约束

- 初始化完成前不得接受自动发射或普通手动执行器动作。
- 关键安全配置缺失、损坏或不可读取时禁止机构动作。
- 启动失败须提供模块名和错误原因给状态/诊断接口。

## 验收条件

- 每个初始化步骤可单独报告成功或失败。
- 全部必需项成功后进入 STANDBY。
- 任一必需项失败时进入 INIT_FAILED，且发射请求被拒绝。
- 关闭时每个已启动模块均收到停止/释放调用。
