# ATOM-05：电机、编码器与 PID 控制

## 元信息

| 项目 | 内容 |
|---|---|
| Atom ID | ATOM-05 |
| 功能类 | 电机、编码器与 PID |
| 程序代号 | Marshland |
| 状态 | 启用 |
| 来源 | PRD 8.4、9、11；Interface 5.1、10；Config 5、13、14 |
| 同步基线 | PRD 0.9、PEF 1.4、Interface 1.4、Config 0.7；2026-09-26 |

## 单一职责

为 Config 映射的所有电机提供命令、反馈、编码器转速和 PID 闭环能力。该 Atom 不决定自动发射流程步骤。

## 电机映射

当前 Config 映射：蓄力电机 1、2；变力电机 4；YAW 电机 3。电机控制和编码器反馈使用 CAN。其他电机仅在 Config 增加映射后纳入。

## 内部原子操作

1. 解析一个电机映射。
2. 校验一个 MotorCommand 的模式、目标值、限幅和当前安全状态。
3. 向单个电机提交一个控制模式和目标。
4. 启用、禁用或停止单个电机闭环通道。
5. 从一帧 CAN 反馈更新单个电机状态。
6. 查询单个电机反馈快照。
7. 从电机反馈中提取有符号转速并确定方向。
8. 判定单个电机/编码器反馈有效性和超时。
9. 读取一个电机的 PIDConfig。
10. 校验一个 PIDConfig 更新请求。
11. 仅在 WEB 控制源且系统模式为手动或调试时接受 PID 修改。
12. 将获准的 PID 参数立即热加载至对应控制回路。
13. 将热加载后的 PID 参数持久化至 Config 指定 JSON 文件，并分别报告生效与保存结果。
14. 对一个电机执行一次 PID 更新并输出一个控制量。
15. 按 Config 周期调度单个电机 PID 更新。
16. 检测 PID 输出 NaN/无穷值。
17. 检测连续 5 个 PID 周期达到输出限幅且控制误差未减小。
18. PID 故障时请求对应电机零力矩、停用该回路并向故障管理器报告。

## 安全约束

- 所有普通电机命令须先经 ATOM-02 和 ATOM-14。
- PID 修改授权唯一为 WEB，允许模式为手动或调试；其他源/模式拒绝且不改变活动参数。
- PID 热加载和文件写入是可观察的分别结果；若持久化失败，不得谎报“已保存”。
- 单个电机反馈异常不得伪装为有效编码器读数。

## 验收条件

- 电机命令、反馈及 PID 参数按电机 ID 独立管理。
- 有符号转速保留方向信息。
- WEB 在手动/调试模式更新 PID 后，运行参数立即生效并尝试按 Config 持久化。
- 其他控制源或模式不能修改 PID。
- PID 异常触发对应电机安全处置和可查询故障。
