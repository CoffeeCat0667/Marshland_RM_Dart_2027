## 单一职责

管理故障记录、安全闸门、一般故障恢复和软件急停锁定/人工解除。硬件动作分别委托 Motor、Charge、Reload、Fire 和 Servo Atoms，不实现 PID 或硬件驱动。

## 一般故障恢复

根因清除且关联接口有效后，按 PEF 执行；换弹相关故障要求左右两侧接口均有效。

1. 分别请求蓄力电机 1、2 回零；两个限位均稳定为低电平才结束回零。
2. 调用 ATOM-11 单次发射三次，逐次确认结果和累计计数；期间所有机构电机零力矩，其他舵机角度不变。
3. 三次成功后请求 ATOM-10 双 M3508 换弹抬起，按 Config 5.6 定时运行后提交两台零转速目标并判定完成。
4. 完成后进入 MANUAL，不恢复旧自动发射上下文。
5. 换弹抬起再次失败时进入 FAULT 锁定，所有电机零力矩、舵机当前角度不变、禁止发射，不自动循环重试；人工处理按既有故障清除契约执行。

## 软件急停锁定阶段

1. WEB/SBUS 急停触发后锁存统一 bool 为 True，并撤销普通动作及未完成恢复动作的出力目标。
2. 按 Config 周期持续发送两组全零安全帧，覆盖全部受控电机，包括换弹左右两侧。
3. 换弹不主动抬起或放下；保持零力矩，不用零转速 PID 代替。
4. 舵机保持当前角度，拒绝一切发射机构舵机指令和所有普通执行器命令。
5. 只接受 WEB/SBUS 人工确认等允许的安全入口，不自动解除。

## 人工确认后的安全恢复阶段

1. 确认后允许换弹双电机抬起及蓄力双电机回零，其他电机零力矩；普通命令和发射仍禁止。
2. 将获准恢复目标交给 Motor/CAN 输出；不得用无条件全零帧覆盖当前获准的恢复出力。
3. 换弹按 Config 定时运行后零转速到位保持，蓄力仍按双限位均低判定回零。
4. 全部恢复成功后急停变量才置 False；不重新初始化、不续跑原自动流程。
5. 恢复期间再次急停立即撤销恢复目标、全部电机零力矩，回到锁定阶段。
6. 恢复换弹抬起再次失败时进入 FAULT，保留尚未解除的急停锁存；所有电机零力矩、舵机角度不变、禁止发射，不自动再次恢复。

## 换弹联动故障

- 任一换弹电机离线、反馈/PID 异常或命令失败，两侧均请求零力矩，ATOM-10 取消动作与计时，不得继续后续流程。
- 不设置换弹动作超时：配置的 3 s 是正常运行时间，电机/编码器/CAN/命令故障仍按 Config 登记。
- 普通换弹故障根因清除后可沿用一般恢复；F-RELOAD-002 恢复失败锁定优先，不得因根因反馈恢复而自动反复重试。

## 故障管理原子操作

- 按 Config 为单个故障登记代码、等级、来源、原因和发生时间。
- 查询当前故障或单条历史故障；分别更新、清除满足策略的单条故障。
- 发布单条故障、恢复阶段或锁定状态事件。
- 一般故障恢复不得覆盖急停锁定；不新增故障清除 HTTP 路由。

## 验收条件

- 一般恢复保持蓄力回零→三次发射→双电机换弹抬起→手动的顺序。
- 急停确认之前所有电机持续零力矩，换弹不产生抬起指令。
- 人工确认之后，仅安全恢复动作可出力；成功才解除锁定，再次急停立即全部零力矩。
- 单侧换弹故障联动两侧零力矩；恢复抬起再次失败锁定 FAULT，不自动重试。
- 软件急停期间拒绝所有发射机构舵机指令；恢复不重新初始化、不续跑旧流程。
