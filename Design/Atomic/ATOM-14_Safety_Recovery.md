## 单一职责

管理故障记录、普通命令安全闸门、一般故障自动恢复及软件急停锁定/人工解除。硬件操作逐项委托给 Motor、Charge、Reload、Fire 和 Servo Atoms。

## 一般故障恢复

一般故障根因清除且关联接口恢复有效后，按 PEF 顺序执行：

1. 分别请求蓄力电机 1 和 2 回零。
2. 只有两个限位都稳定为低电平时才结束回零阶段。
3. 调用 ATOM-11 单次 FireAction 三次，每次成功后分别累计计数。
4. 三次发射期间，其他机构电机保持零力矩，其他舵机角度不变。
5. 三次完成后请求换弹机构抬起，并等待动作组到位判定。
6. 恢复完成后进入 MANUAL；不恢复原自动发射上下文。

## 软件急停

1. 接受 WEB 或 SBUS 急停请求，将统一 bool 急停变量锁存为 True。
2. 按 Config 周期持续发送两个 8 字节零力矩 CAN 帧：`1.200#0000000000000000` 和 `2.1FF#0000000000000000`；多字节数据使用 Config 定义的大端序。
3. 请求换弹机构抬起安全动作。
4. 拒绝所有普通执行器动作，尤其拒绝任何发射机构舵机目标写入。
5. 只接受 WEB/SBUS 人工确认请求；不得自动解除。
6. 人工确认后请求换弹抬起，并分别请求蓄力电机 1、2 回零。
7. 两个蓄力限位均低且换弹抬起步骤完成后，急停变量方可置为 False。
8. 不重新初始化，不自动恢复原自动发射流程。

## 故障管理原子操作

- 按 Config 为单个故障登记代码、等级、来源、原因和发生时间。
- 查询当前故障或单条历史故障。
- 更新单条故障恢复状态。
- 按 Config 条件清除故障。
- 发布单条故障/恢复状态事件。
- 一般故障自动恢复不覆盖急停锁定流程。

## 验收条件

- 一般恢复顺序为蓄力电机 1/2 回零→发射动作三次→换弹抬起→手动状态。
- 急停期间持续发送 Config 指定的两个 8-byte 零力矩帧。
- 急停期间拒绝一切发射舵机普通命令。
- 急停解除需人工确认并完成换弹抬起和蓄力机构两个电机回零；不重新初始化、不续跑旧自动流程。
