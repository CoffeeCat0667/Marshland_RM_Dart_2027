## 单一职责

维护系统模式、自动流程状态和当前控制源选择结果；校验每条命令的模式、安全条件和发射授权。此 Atom 不直接发送 CAN/IIC 报文，也不执行机构动作。

## 控制源语义

必须区分“当前控制源选择结果”和“实际发射动作授权优先级”。

### 当前控制源选择

1. 程序启动且无 WEB 客户端连接时，初始控制源为 `AUTO`。
2. 存在 WEB 连接且无更高优先级条件成立时，控制源为 `WEB`。
3. SBUS 在线且“自动模式”标志为 `True` 时，控制源选择结果为 `AUTO`；此时 SBUS 与 WEB 仍可按规定介入自动流程。
4. SBUS 在线且“自动模式”标志为 `False` 时，按 `SBUS > WEB` 选择。
5. SBUS 失联时降级至 WEB；有效 SBUS 帧恢复后，重新应用自动模式标志与 SBUS 优先规则。

### 实际发射授权

实际发射动作授权始终严格为：

```text
SBUS > WEB > 自动流程
```

软件急停高于所有普通控制源。每次 FireAction 前必须重新检查发射授权、停止发射标志、故障和急停状态。

## 状态/仲裁原子操作

1. 查询当前系统模式和自动流程状态。
2. 校验并提交一次合法状态转换。
3. 发布一条含旧状态、新状态和原因的状态事件。
4. 更新当前控制源选择结果。
5. 根据 SBUS 自动模式标志计算控制源选择结果。
6. 对一个有效 SBUS 普通控制意图执行仲裁。
7. 对一个有效 WEB 控制意图执行仲裁。
8. 拒绝低优先级冲突命令，且不修改控制目标。
9. 在实际发射前复核发射授权。
10. SBUS 实际接管自动流程时，允许当前硬件动作组完成，然后终止原流程；不得暂停或恢复旧流程。
11. SBUS 失联时控制源降级至 WEB；恢复有效帧后按自动模式标志恢复源选择。已终止的自动流程不得续跑。
12. 软件急停为 True 时拒绝普通控制意图。
13. 记录每次控制源变化和抢占原因。
14. 在将控制权交给调试或校准原子操作时，将系统模式切换为 DEBUG 或 CALIBRATION。

## 安全约束

- 控制源选择结果不改变实际发射授权优先级。
- 自动模式标志为 True 时当前控制源可以显示为 AUTO，但 SBUS/WEB 仍可介入；介入命令仍须仲裁。
- 急停不可由普通模式切换解除。
- 状态机只负责状态/授权，不直接向硬件发命令。

## 验收条件

- 控制源选择遵循 Config 7.2；发射授权始终为 `SBUS > WEB > 自动流程`。
- SBUS 接管后当前硬件动作组完成再终止自动流程，旧流程不可续跑。
- SBUS 失联降级至 WEB，恢复后重新应用 SBUS 最高优先规则。
- 未授权、停止发射、故障或急停状态下不进入 FireAction。
