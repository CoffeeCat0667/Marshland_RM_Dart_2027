# ATOM-03：SBUS 遥控输入

## 元信息

| 项目 | 内容 |
|---|---|
| Atom ID | ATOM-03 |
| 功能类 | SBUS 遥控输入 |
| 程序代号 | Marshland |
| 状态 | 启用 |
| 来源 | PRD 6、7.4、14；PEF 3、8；Interface 9.1；Config 2、7 |
| 同步基线 | PRD 0.10、PEF 1.5、Interface 1.6、Config 0.9；2026-10-13 |
| 硬件 | 天地飞 ET16S 接收机；UART10；硬件电平反转；串口参数由 RuntimeContext 传入 |

## 单一职责

从已完成硬件电平反转的 UART10 独立线程读取 25 字节 SBUS 帧，校验并解析通道值，写入带互斥锁保护的公共通道结构体；再将通道值映射成控制意图、安全意图或模式标志，提交给 ATOM-02/ATOM-14。软件不校验帧尾，SBUSAdapter 不直接驱动电机或舵机。

## 接收与解析原子操作

1. 从 RuntimeContext 指定参数对应的 UART10 读取一个 25 字节 SBUS 帧，读取线程独立运行。
2. 校验帧长度和通道数值有效性；不校验帧尾；无效帧不刷新有效帧时间。
3. 解码 CH1～CH16 的通道值，并在互斥锁保护下原子替换公共通道快照。
4. 将一个通道值映射为单一手动动作、自动模式标志、停止发射或急停意图。
5. 按 Config 校验连续值中心 1024 和范围 364～1684；连续输出使用 `(raw - 1024) * x`，`x` 由 RuntimeContext 传入。
6. 按 Config 校验 CH5～CH7 的离散值；CH12 映射为变力机构速度，CH13～CH16 保持未映射。
7. 更新最近有效帧的单调时钟时间戳。
8. 判断是否达到 SBUS 失联阈值。

## 通道映射

| 通道 | 映射 |
|---|---|
| CH1 | 空 |
| CH2 | 蓄力机构速度 |
| CH3 | 换弹机构速度 |
| CH4 | YAW 电机速度 |
| CH5 | AUTO / WEB / SBUS 控制权分配：364=AUTO、1024=WEB、1684=SBUS |
| CH6 | 软件急停：`raw - 1024 > 0` 正常，`raw - 1024 < 0` 急停，0 为中点 |
| CH7 | 发射：原始值 364 连续 20 个有效帧后确认 |
| CH8 | 蓄力机构左电机速度 |
| CH9 | 蓄力机构右电机速度 |
| CH10 | 换弹机构左电机速度 |
| CH11 | 换弹机构右电机速度 |
| CH12 | 变力机构速度：364=-2000 rpm、1024=0 rpm、1684=+2000 rpm |
| CH13～CH16 | 保留，当前不映射 |

通用连续通道原始值为 1024 ± 660（364～1684），映射为 `(raw - 1024) * x`，其中 `x` 为 `RuntimeContext::values["sbus.channel_scale_x"]`，类型为 `uint8_t`，取值 1～10。CH12 使用专用变力范围映射：`(raw - 1024) * 2000 / 660`，输出范围为 -2000～+2000 rpm，不应用通用 `x` 缩放；CH5 为 364=AUTO、1024=WEB、1684=SBUS；CH6 以 `raw - 1024` 判断，正值为正常、负值为急停、0 为中点；CH7 原始值 364 连续保持 20 个有效帧后才形成发射请求。

## 控制源与动作意图

1. SBUS“自动模式”标志为 True 时，向 ATOM-02 提供 AUTO 模式标志；SBUS/WEB 仍可按控制规则介入自动流程。
2. 自动模式标志为 False 时，有效 SBUS 控制源按 `SBUS > WEB` 参与控制源选择。
3. 每个普通 SBUS 动作意图均提交给 ATOM-02 仲裁，不直接执行机构动作。
4. 急停触发和人工确认意图分别提交给 SafetyManager。
5. SBUS 支持的动作映射以 Config 7.1 为唯一来源；`[待定]` 通道不得臆造。

## 失联和恢复

1. 超过 Config 的失联时间没有有效帧时，撤销 SBUS 普通控制有效性并停止接受 SBUS 普通命令。
2. 失联后将当前普通控制源降级为 WEB。
3. 重新收到有效帧后，恢复 SBUS 优先级，并依据“自动模式”标志重新选择控制源。
4. SBUS 重连不得恢复先前已终止的自动发射流程。
5. 急停锁定不因 SBUS 断连或重连自动解除。

## 验收条件

- 有效帧可产生 Config 映射的单一控制意图。
- 无效帧不更新有效帧时间，也不产生机构命令。
- SBUS 失联达到阈值后降级至 WEB；恢复后重新应用 SBUS 优先规则。
- 自动模式标志与手动动作意图分别解析并提交。
- SBUS 急停/人工确认仅提交安全请求，不绕过 SafetyManager。
