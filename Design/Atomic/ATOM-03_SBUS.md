# ATOM-03：SBUS 串口读取与数值转换

- 更新日期：2026-10-16。
- 以用户最新决定为准：只负责串口读取、SBUS 组帧解码、数值转换及公共数据写入。
- 代码文件严格限定为一个私有头文件、一个 cpp、一个公共 Sbus.hpp。

## 文件边界

| 文件 | 职责 |
|---|---|
| Atoms/ATOM-03_SBUS/Inc/atom03_SBUS/sbus_private.hpp | 内部环形缓冲、解码声明和载荷长度常量 |
| Atoms/ATOM-03_SBUS/Src/sbus.cpp | 串口打开/配置/read/关闭、组帧、解码和转换 |
| Atoms/Public/Sbus.hpp | 公共 SbusData 及一个阻塞接收函数 ReceiveSbus |

不保留生命周期适配器、模块注册、配置管理、IConfigView、RuntimeContext、独立串口类或 UART 抽象。不在模块内创建线程，不提供 start/stop 管理对象。

## 接收入口

`marshland::sbus::ReceiveSbus()` 接收设备名、SbusData、停止标志、x、帧长、中点、最小值、最大值和读取超时。

- 函数在当前调用线程内阻塞接收，由调用方自行放到独立线程运行。
- 停止标志类型为 `const std::atomic<bool>&`；调用方置 true 后，接收函数在下一次 poll 返回或数据批次处理后退出，不提供立即 cancel()。
- 默认无数据等待超时 20 ms，也可由参数指定；停止等待时间受该参数及调度/锁等待影响。
- 正常请求停止返回 true；参数错误、设备打开/配置失败或永久 I/O 错误返回 false。
- 所有返回路径释放已打开的串口。永久设备错误不自动重试或重开，不产生错误空转。

## 串口与组帧

- 设备路径为参数，不固定 UART10；串口格式在代码中固定 100000 baud、8 数据位、偶校验、2 停止位。
- 使用 Linux 原生 termios2、BOTHER 和 ioctl；使用原始模式，关闭软硬件流控，电平反转由硬件完成。
- poll/read 批量读取，有限容量环形缓冲区直接保存半帧，持续消费已经到达的完整帧。
- 帧长使用参数，不硬编码标准帧长；0x0F 为帧头，不校验帧尾，不解析 Byte 23 状态。
- 解码 CH1～CH16 的 11-bit 数值；通道超出传入范围的整帧不覆盖公共数组。
- 保留最短通道载荷和 minimum<center<maximum 等内存/运算安全检查，不要求固定标定值。

## 数值范围

- 数组下标 0～15 对应 CH1～CH16。
- 通用映射：`(raw - center) * x`，x 为 uint8_t，许可范围 1～10。
- 推荐标定 minimum=364、center=1024、maximum=1684，输出 `-660*x`～`+660*x`。
- CH12（下标 11）不使用 x；以 center 为界分别使用负、正量程缩放，minimum/center/maximum 对应 -2000/0/+2000 rpm。
- CH7 为发射输入，保存到 scaled_channels[6]；CH13 为供弹舵机输入，保存到 scaled_channels[12]。两者独立使用同一个通用公式 `(raw-center)*x`，均无持续帧数确认、动作请求或舵机角度/PWM 转换。
- CH14～CH16 保留，不映射为动作；CH5、CH6 的控制权/急停含义也由消费方解释，ATOM-03 只保存数值。
- CH2/3/4、CH8～CH12 的机构含义由消费方决定，ATOM-03 不产生机构命令。

## 公共结构体

`SbusData` 只保留 mutex、scaled_channels 和 online。公共头不依赖任何其他 ATOM；原始值仅为接收过程中的局部变量，不公开。

- 调用方提供一份 SbusData，接收函数是唯一写入方；所有读写都持有其 mutex。
- 消费方使用 const SbusData& 并持锁复制字段，不保留内部数组元素引用。
- online 初始为 false；进入接收函数先置 false，有效整帧在同一次加锁中替换全部映射通道并置 true。
- 无数据 poll 超时、无效数据、读取异常、参数/设备失败和函数退出均令 online=false，不覆盖上次通道值；消费者必须在同一把锁内复制数组及 online，不能使用离线旧值作为新输入。
- online 反映最近的接收/超时/异常事件，不是独立按帧龄运行的看门狗或动作授权；锁只保证数据一致性，不证明获得控制权或执行权限。
- 无时间戳、序号、统计信息、发射确认和业务状态。ReceiveSbus 的返回契约不变，不用数组内容代替函数错误处理。
- 调用方保证数据及停止标志在接收期间存活，不得持有数据锁等待接收函数结束。

## 明确排除

生命周期管理、配置文件读取、线程创建/注册、仲裁、安全上报、发射授权、自动流程、失联降级、执行器调用及外部调用方迁移均不属于此次实现。
