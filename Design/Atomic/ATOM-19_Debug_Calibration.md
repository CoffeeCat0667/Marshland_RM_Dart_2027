# ATOM-19：调试与校准

## 元信息

| 项目 | 内容 |
|---|---|
| Atom ID | ATOM-19 |
| 功能类 | 调试状态查询与校准流程接口 |
| 程序代号 | Marshland |
| 状态 | 启用（具体校准项目按配置/后续设计） |
| 来源 | PRD 7.5、7.6、12.2；Interface 5、14、19；Config 3、11 |
| 同步基线 | PRD 0.9、PEF 1.4、Interface 1.4、Config 0.7；2026-09-26 |

## 单一职责

提供调试信息查询和校准步骤管理接口。该 Atom 不定义机械校准算法，不直接绕过 SafetyManager 控制硬件。

## 调试原子操作

1. 查询一个电机控制状态。
2. 查询一个编码器状态。
3. 查询一个电机 PID 参数/运行状态。
4. 查询一个 GPIO/限位状态。
5. 查询一个舵机目标与驱动状态。
6. 查询 CAN 接口状态。
7. 查询 PCA9685A/IIC 状态。
8. 查询一个机构当前状态和最近错误。

## 校准原子操作

1. 接收单步校准命令；由主状态机在将控制权交给本 Atom 的校准操作时转入 CALIBRATION 模式；本 Atom 不要求进入前已处于校准模式。
2. 将该步骤授权交给对应机构控制器。
3. 更新一个校准步骤的进行中状态。
4. 发布一个校准步骤的成功结果。
5. 发布一个校准步骤的失败结果和原因。
6. 禁止把未定义的校准项目或判据擅自补成具体动作。

## 安全与待定边界

- 急停、故障锁定或未初始化状态下拒绝普通调试/校准执行命令。
- 校准项目、参数、范围和完成判据使用 Config 的 `[待定]` 项或经后续设计确认的配置。
- 调试查询只读，不因此获得更高控制权。

## 验收条件

- 调试查询只返回状态，不直接下发执行器目标。
- 校准执行请求由主状态机转入 CALIBRATION 模式后执行，进入无需前置模式校验。
- 每个校准步骤都有独立的进行中、成功或失败结果。
- 未在 PRD/Config/后续设计中定义的校准算法不被本 Atom 自行假设。
