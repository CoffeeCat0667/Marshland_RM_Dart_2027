## 单一职责

把一个逻辑舵机目标映射为一个配置通道输出，并处理 PCA9685A 初始化、就绪查询和 IIC 错误。此 Atom 不决定哪一流程应移动舵机。

## 内部原子操作

1. 通过配置 IIC 设备和 PCA9685A 地址打开设备。
2. 调用驱动初始化并读取驱动就绪状态。
3. 设置 Config 指定的 PWM 频率。
4. 校验一个舵机目标是否落在该舵机配置范围内。
5. 将一个角度转换为一个 PWM/脉宽输出目标。
6. 向单个 PCA9685A 通道写入一个目标。
7. 查询一个舵机最近接受的目标值；不得将目标值冒充物理反馈。
8. 对一次 IIC 错误发布故障结果。
9. 急停/通信异常要求保持时不下发新的普通角度目标。
10. 急停例外允许由安全管理请求换弹抬起；FireController 的目标命令仍由安全闸门拒绝。

## 硬件约束

- IIC 和 PCA9685A 访问串行化。
- OE 按硬件约束拉低后才输出 PWM。
- 通道、角度、频率、地址和脉宽均从 Config 读取；库 README 中参考值不是项目默认值。

## 验收条件

- 单通道写入返回成功/失败。
- 角度越界按 Config 策略处理。
- IIC 错误可查询并上报。
- 不存在绕过控制器直接访问 PCA9685A 的普通业务命令。
