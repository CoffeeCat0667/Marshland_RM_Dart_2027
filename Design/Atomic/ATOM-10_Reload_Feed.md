# ATOM-10：换弹与供弹机构控制

## 元信息

| 项目 | 内容 |
|---|---|
| Atom ID | ATOM-10 |
| 功能类 | 换弹与供弹机构控制 |
| 程序代号 | Marshland |
| 状态 | 启用 |
| 来源 | PRD 8.2、8.3；PEF 5；Interface 5.1、8、10.6、12、17；Config 4、5.6、9、14 |
| 同步基线 | PRD 0.10、PEF 1.5、Interface 1.5、Config 0.8；2026-10-10 |

## 单一职责

协调同一换弹机构左右两个 M3508 的速度闭环动作，并维护独立的单舵机供弹动作。换弹电机通过 ATOM-05/ATOM-04，供弹舵机通过 ATOM-07；本 Atom 不直接实现 CAN/IIC 驱动或 PID 算法，不判断已供弹或卡弹。

## 换弹动作组内部原子操作

1. 读取 Config 5.6 的本动作左右电机映射、速度目标及运行时间。
2. 校验本动作的控制权、安全条件与两侧电机可用状态。
3. 向左电机提交本动作速度目标（抬起正转、放下反转）。
4. 向右电机提交本动作速度目标（抬起反转、放下正转）。
5. 两台运行目标均成功提交后启动单调时钟计时；不等待速度反馈达到目标才计时。
6. 检查左电机反馈与控制状态，异常时报告联动失败。
7. 检查右电机反馈与控制状态，异常时报告联动失败。
8. 检查本动作运行计时是否到期。
9. 到期后向左电机提交 0 rpm 速度目标。
10. 到期后向右电机提交 0 rpm 速度目标。
11. 两台 0 rpm 目标均成功且本动作未取消/失败时，更新为对应抬起到位或放下到位状态。
12. 正常到位后向 ATOM-05 维持左电机 0 rpm 速度闭环目标。
13. 正常到位后向 ATOM-05 维持右电机 0 rpm 速度闭环目标。
14. 手动停止、急停或单侧故障时取消本动作及完成资格，使其计时结果不再有效。
15. 中止或失败时向左电机请求零力矩。
16. 中止或失败时向右电机请求零力矩。
17. 拒绝已取消/失败动作的迟到完成事件。
18. 按当前双电机动作组完成边界移交控制源；急停、手动停止和故障不等待该正常边界。
19. 初始化时建立逻辑默认抬起状态，不声称已测量物理位置。
20. 初始化成功后向左电机建立 0 rpm 目标，不主动执行抬起。
21. 初始化成功后向右电机建立 0 rpm 目标，不主动执行抬起。

每个电机的提交、监测与输出独立返回结果；任一失败使本动作失败并执行两侧零力矩步骤。上述步骤不执行换弹软件校准、回零或本版本限位检测。

## 供弹动作内部原子操作

1. 向供弹舵机写入角度二（换弹位）。
2. 从供弹动作触发时刻开始启动 PEF 指定 2 秒等待计时。
3. 角度二保持配置的 100 ms 到期后向供弹舵机写回角度一（待机）。
4. 舵机回到角度一目标后标记供弹动作完成。
5. PEFExecutor 独立等待从触发时刻起算的 2 秒到期，再请求换弹放下。

## 限制与故障边界

- 换弹速度与持续时间统一见 Config 4、5.6（当前速度幅值 2000 rpm，抬起/放下各 3 s），不采用旧四舵机角度或 500 ms 延时。
- 换弹到位采用定时判定，不代表存在物理位置反馈；不设置换弹动作超时，但通用电机、编码器、PID、CAN 异常及命令失败仍有效。
- 零转速闭环保持和零力矩必须区分：正常到位为前者，手动停止、急停或联动故障为后者。
- 急停锁定阶段不抬起；只有人工确认后的安全恢复或一般故障恢复对应阶段允许抬起。
- 电机 ID、节点及 PID 具体值仍以 Config 为准；供弹舵机编号、通道、角度及时序保持原定义。
- 两个硬件命令分别提交，不承诺物理同步原子写入或回滚；任一提交失败联动两侧零力矩并报告失败。
- 恢复抬起再次失败交 ATOM-14 进入 FAULT 锁定，不自动循环重试。

## 验收条件

- 抬起左右目标为 +2000/-2000 rpm，放下为 -2000/+2000 rpm，均按 Config 运行 3 s 后提交两台 0 rpm 并判定到位。
- 到位与供弹等待期间保持速度 PID；手动停止、急停或单侧故障两台零力矩，不产生迟到成功。
- 启动不产生换弹抬起/回零/校准动作，本版本不读取换弹限位。
- 供弹仍为角度一→角度二→保持 100 ms→角度一，2 秒流程计时从供弹触发起算。
- 换弹故障不冒充舵机 IIC 故障；供弹 IIC 写入失败仍不得报告供弹完成。
