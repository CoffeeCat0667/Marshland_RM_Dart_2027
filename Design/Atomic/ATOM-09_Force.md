## 单一职责

接受一个变力目标，交给 Config 映射的变力电机（当前 ID 4）闭环执行，并提供目标、当前反馈和动作状态。此 Atom 不安排发射流程顺序。

## 内部原子操作

1. 校验一个变力目标的类型、模式、授权和 Config 范围。
2. 提交一个变力目标给 ForceController。
3. 将目标交给 ATOM-05 对应电机执行闭环/PID。
4. 接收一条电机反馈并更新变力当前状态。
5. 执行一次配置时间 X 秒的变力动作计时。
6. X 秒到期后将本次变力动作状态置为完成。
7. 查询目标、反馈、动作状态和错误。
8. 将通用电机/PID/CAN 故障报告给 ATOM-14。

## 与自动流程的关系

- 第 1 至第 4 发均执行一次变力动作。
- 第 1 发在蓄力完成后执行变力。
- 第 2 至第 4 发在换弹抬起/供弹等待/放下完成后执行变力。
- 变力完成判据为执行配置时间 X 秒到期；目标和时间读取 Config。

## 故障边界

本机构不另设专属异常恢复策略。变力电机、PID、编码器或 CAN 故障使用通用故障表和 PEF 一般故障恢复规则。

## 验收条件

- 每发恰执行一次变力动作。
- 变力目标只作用于 Config 映射电机。
- 无效目标不改变当前有效目标。
- X 秒到期前不报告变力完成。
- 机构专属异常处理不超出 Config 已定义的通用处理规则。
