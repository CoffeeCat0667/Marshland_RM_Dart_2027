# ATOM-06：GPIO 与限位输入

## 元信息

| 项目 | 内容 |
|---|---|
| Atom ID | ATOM-06 |
| 功能类 | GPIO 与限位输入 |
| 程序代号 | Marshland |
| 状态 | 启用；压力传感器不属于本版本 |
| 来源 | PRD 9.4、14；PEF 7、8；Interface 11；Config 8 |
| 同步基线 | PRD 0.9、PEF 1.4、Interface 1.4、Config 0.7；2026-09-26 |

## 单一职责

采样 GPIO 和蓄力限位开关，维护去抖后的有效输入状态，并向状态机/安全管理发布输入事件。输入适配器不自行驱动机构。

## 内部原子操作

1. 按 Config 周期读取一个 GPIO 输入。
2. 对一个输入样本执行 Config 定义的去抖。
3. 更新一个限位开关的稳定电平和有效状态。
4. 查询一个限位开关的电平/有效状态。
5. 判断一个限位开关是否为低电平。
6. 判断蓄力回零条件：两个蓄力限位均稳定为低电平。
7. 发布一个 GPIO/限位状态变化事件。
8. 将 GPIO 读取失败或无效输入报告给故障管理器。

## 本版本范围

压力传感器已经从当前版本产品范围中移除，不执行压力传感器接入、采样、状态发布、诊断或安全判定。若未来重新纳入，须先同步更新 PRD、PEF、Interface、Config 和对应 Atom。

## 验收条件

- 蓄力回零条件仅在两个稳定限位均为低时成立。
- GPIO 读取失败不产生伪造电平。
- 本版本不创建压力传感器运行功能。
