## 单一职责

提供 SocketCAN 初始化、单帧收发、协议解析入口、节点状态和错误事件。CANAdapter 不承担机构流程判断或 PID 计算。

## CAN 传输原子操作

1. 打开 Config 指定的 SocketCAN 接口。
2. 接收一个 CAN 帧并报告帧或接收错误。
3. 将一个原始帧分派至对应设备协议解析器。
4. 发送一个已构造并校验的 CAN 帧。
5. 更新一个 CAN 节点的在线状态。
6. 发布一次 CAN 总线或节点错误变化。
7. 根据 Config 周期/触发策略调度电机控制和状态帧。
8. 对发送失败返回明确错误，不虚报成功。

## 电机 CAN 帧语义

- Config 6.2 定义两组电机控制帧：CAN ID `0x200` 对应 `1.200#AABBCCDD`，CAN ID `0x1FF` 对应 `2.1FF#EEFFGGHH`；每帧 DLC 为 8 字节，负载为 4 个有符号 int16 电流值，顺序按 Config 电机表。
- 多字节值一律大端序，高字节先发。
- 电机反馈 ID、字段布局、单位和错误映射以 Config 6.2 与 `Docs` 设备资料为准。

## 零力矩安全帧

所有受控电机进入零力矩时，发送两组 8 字节帧：

```text
0x200 / 1.200#0000000000000000
0x1FF / 2.1FF#0000000000000000
```

按 Config 规定的安全周期持续发送，不闭环确认；零力矩帧发送失败时报告 CAN 故障并执行全机静默策略。

## 验收条件

- 收发路径能区分成功、超时、BUS_OFF 和总线错误。
- 接收帧按 Config/设备协议解析，不臆造 ID 或字段。
- 两组电机控制帧均使用 8 字节 payload 和大端序。
- 零力矩帧 payload 为 8 字节全零，发送失败触发规定安全处理。
